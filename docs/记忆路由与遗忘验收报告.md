## 4. 仍然失败的4题

失败ID是routing-v2-short_forget-00/01/02/03。用户撤回回答风格后，实际输入均只有：

```json
[{"role":"user","content":"我要求的回答详细程度是什么？"}]
```

旧风格没有从近期、摘要或事实重新注入，但问答模型仍复制评测提示中的示例“简短答案，只含所问内容”，并返回abstain=false。四题全部保留为严格失败，没有用关键词修正拒答字段。

两题因“简短”还被字面禁止值规则标记；这里不能直接据此断定旧原文穿过了存储过滤，也不能宣称最终回答层已完全满足遗忘。问题仍属于无证据回答/拒答一致性，且目前是在共同评测提示下观察到，未证明完整业务Agent有相同错误率。

## 8. 结果适用范围

这些是内部定向合成验收/已知题回归，不是线上准确率或外部独立评测。历史准备运行生产分析器与真实SQL事务；当前请求运行真实ChatService上下文准备。普通最终回答用共同结构化评测提示，没有运行JWT、产品业务工具的完整Agent链路。
